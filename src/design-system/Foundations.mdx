# Foundations

Os foundations são os valores compartilhados entre a aplicação e os componentes do design system. Prefira tokens semânticos a valores hexadecimais ou sombras locais.

## Tipografia

Família padrão: `--ds-font-sans` (`Inter`).

O sistema usa a escala tipográfica do shadcn/Tailwind. Não crie tamanhos intermediários; escolha sempre um dos tokens abaixo.

| Token | Tamanho / altura de linha | Uso típico |
| --- | ---: | --- |
| `--ds-font-size-xs` | 12px / 16px | Metadados, captions e badges |
| `--ds-font-size-sm` | 14px / 20px | Texto padrão da interface, labels e controles |
| `--ds-font-size-base` | 16px / 24px | Texto de destaque e títulos compactos |
| `--ds-font-size-lg` | 18px / 28px | Títulos de painéis |
| `--ds-font-size-xl` | 20px / 28px | Títulos de seção |
| `--ds-font-size-2xl` | 24px / 32px | Títulos de página |
| `--ds-font-size-3xl` | 30px / 36px | Display compacto |
| `--ds-font-size-4xl` | 36px / 40px | Display amplo |

## Espaçamento

| Token | Valor | Uso típico |
| --- | ---: | --- |
| `--ds-space-1` | 4px | Gaps compactos |
| `--ds-space-2` | 8px | Ícone + label |
| `--ds-space-3` | 12px | Padding de controles |
| `--ds-space-4` | 16px | Padding de cards |
| `--ds-space-5` | 20px | Separação de seções |
| `--ds-space-6` | 24px | Margens de layout |

Use múltiplos de 4px para manter ritmo e previsibilidade entre componentes.
